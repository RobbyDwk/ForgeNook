Enhances manual data entry with automated form filling and validation for non-technical users.

- automated form filling and validation
- for non-technical users

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/ForgeNook.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ForgeNook is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
